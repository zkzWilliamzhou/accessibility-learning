# accessibility-learning

Gamified accessibility learning platform.

## Why?

Accessibility (a11y) is legally mandated in many jurisdictions, but most training is dry text-based courses. This platform makes accessibility learning interactive, hands-on, and gamified with screen reader simulation and progressive certification.

## Features

- **Screen reader simulation**: Experience websites as screen reader users do
- **Hands-on challenges**: Fix real accessibility issues in interactive exercises
- **Gamified progress**: Earn badges, unlock levels, track completion
- **Progressive certification**: From beginner to expert, with verifiable credentials
- **Corporate training ready**: Team dashboards, progress tracking, compliance reporting
- **Real-world scenarios**: Based on actual WCAG violations found in production

## Quick Start

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build
```
